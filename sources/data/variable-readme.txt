Lato26 Variable

Lato26-Variable.ttf: upright, weight 100-900, default 400.
Lato26-VariableItalic.ttf: italic, weight 100-900, default 400.

Both fonts contain the nine named weights Hairline, Thin, Light, Regular,
Medium, Semibold, Bold, Heavy and Black. Applications that support variable
fonts can also select intermediate weights.

The family name is Lato26 Variable, so these can coexist with the static
Lato26 family. The fonts include the current narrower l bowl, the enlarged
upright a bowl, and the four-master upright e refinement. Automatic fi/ffi
ligatures use the connected, dotless Lato 2.015 designs, with corresponding
ogonek, dot-below, tilde-below and stroked-i forms. All nine named weights
have dedicated compatible outlines. Other source substitution features remain.

Special l-pair outline-edge gaps match the static TTFs within half a unit at
the four masters, with tiny interpolation/conversion differences between them.

Positive l/punctuation kerning follows Fira Sans, scaled to 2,000 UPM. The
period/comma/ellipsis group gains 0, 0, 4, 8, 12, 14, 16, 18 and 20 units at
the nine named weights, with continuous interpolation between them. Colon,
semicolon and Greek question mark gain 20 units throughout. This applies
to both styles and related l forms; letter pairs and fl ligatures are unchanged.
Editable Glyphs sources contain this punctuation kerning at their four masters;
the repository exporter supplies the exact nine-weight curve in these binaries.

Line metrics match published Lato 2.015 and the static Lato26 fonts: hhea
ascent/descent 1974/-426 with zero line gap (2,000 units per em). Windows
ascent/descent are 1974/426. The total line height is 2,400 units.

These variable fonts are UNHINTED. Use the static Lato26 desktop TTFs for the
existing Lato 2.015-based native TrueType hinting and Bold a join correction.
