Lato26 Variable — upstream Lato 3.100 with custom ss05

Default forms follow upstream Lato. Enable OpenType stylistic set ss05 to use
our tailed lowercase l, revised a and e, and their related forms and kerning.
The existing upstream ss05 capital-I alternates remain available.
